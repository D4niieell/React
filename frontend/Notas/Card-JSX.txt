## Estrutura geral

```javascriptreact
const Card = ({ livro }) => { ... }
```

Isso é um **componente funcional** do React chamado `Card`. Ele é uma função (usando arrow function) que recebe **props** como parâmetro.

## Destructuring das props

```javascriptreact
({ livro })
```

Em vez de receber `props` inteiro e depois acessar `props.livro`, aqui já se está "desestruturando" o objeto de props diretamente no parâmetro da função. Ou seja, isso é um atalho para:

```javascriptreact
const Card = (props) => {
  const livro = props.livro;
  ...
}
```

Isso significa que, ao usar esse componente, você precisa passar uma prop chamada `livro`:

```jsx
<Card livro={meuLivroObjeto} />
```

## O JSX retornado

```jsx
return (
  <div className="livro">
    <h1>{livro.titulo}</h1>
    <p>{livro.autor}</p>
  </div>
);
```

- `<div className="livro">` — cria uma div com a classe CSS `livro` (usa `className` porque `class` é palavra reservada em JavaScript).
- `<h1>{livro.titulo}</h1>` — mostra o título do livro. As chaves `{}` permitem inserir expressões JavaScript dentro do JSX.
- `<p>{livro.autor}</p>` — mostra o autor do livro.

Ou seja, esse componente espera que `livro` seja um objeto parecido com:

```js
{ titulo: "Dom Casmurro", autor: "Machado de Assis" }
```

## Exportação

```javascriptreact
export default Card;
```

Isso torna o componente `Card` disponível para ser importado e usado em outros arquivos, por exemplo:

```jsx
import Card from './Card';

<Card livro={{ titulo: "1984", autor: "George Orwell" }} />
```

## Resumindo

Esse componente é um **cartão de exibição de livro**: ele recebe um objeto `livro` como prop e renderiza o título e o autor em elementos HTML formatados dentro de uma `div`. É um padrão bem comum em React para criar componentes reutilizáveis que exibem itens de uma lista (por exemplo, uma lista de livros de uma biblioteca).
